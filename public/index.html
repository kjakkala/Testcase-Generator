How to Setup & Use
⚙️ Setup
1
Choose an AI provider
Open ⚙ Settings → Generation provider. GitHub Models uses your personal token; Amazon Bedrock uses shared AWS credentials configured by an Admin.
2
Jira Configuration
In ⚙ Settings → Jira, enter your:
  • Base URL — e.g. https://yourcompany.atlassian.net
  • Email — your Jira login email
  • API Token — generate at id.atlassian.com → Security → API Tokens
3
TestRail Configuration (optional)
In ⚙ Settings → TestRail, enter URL, numeric Project ID, Suite ID, TestRail Email, and API Key.
The Assigned to list is loaded from project-accessible users. If your role cannot list all users, the app auto-assigns the current API-token user.
🚀 How to Use
1
Add a Section & Jira Ticket
Click + Add another section at the bottom. Select a TestRail folder from the dropdown, then enter a Jira key (e.g. CIMPL-1234) and click ⌖ Fetch to load acceptance criteria from Jira.
2
Generate Test Plan or Test Cases
Use either button per ticket:
☆ Generate Test Plan — bullet-point scenarios grouped by QA category.
≡ Generate Test Cases — detailed step-by-step test cases.
Or click ☆ Generate all (bottom bar) to run all tickets at once.
3
Review in Tabs & Edit
Results appear below each ticket with Test Plan and Test Cases tabs when both are generated. All content is editable inline — click any title, scenario, step, or expected result to edit. Use + Add scenario or + Add test case to add entries manually.
4
Upload to TestRail
Click ↑ Upload to TestRail (bottom bar) to push all generated test cases to your TestRail project. A TestRail folder must be selected for each section before uploading.
After upload, each ticket shows an Execution Plan strip.
5
Assign Plan, User, and Update Status
In the Execution Plan strip, choose an open plan and assign cases. Use Assigned to to pick a project-accessible user, or use auto-assign when only your API-token user is available.
For each test case, select status and click update. When status is Failed, you can create a Jira bug subtask and the bug key is linked back to TestRail defects.
6
Create Jira Subtask
After generating a test plan, click the → Jira Subtask button in the results header. This creates a QA-testing subtask under the Jira ticket with test-plan and AI labels and the generated plan as description.
7
Download Plans
Click ↓ Plan .docx in the results header for a single ticket export. Use Download Full Plan (bottom bar) to export all sections as one Word document.
💡 Tip: Click the 📊 Session Tokens widget in the header to view your monthly token usage and estimated AI cost history.
